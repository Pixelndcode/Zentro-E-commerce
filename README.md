# 🛍️ Zentro - Modern E-Commerce Product Catalog

## 📌 Description

Zentro is a modern and responsive e-commerce product catalog website designed to provide users with a smooth and engaging online shopping experience.

The website allows users to explore different products, view product details, search items, add products to wishlist, and manage their shopping preferences with an attractive and user-friendly interface.

Zentro focuses on clean design, responsive layouts, and interactive features to create a premium online shopping experience.

## ✨ Features

- 🛒 Product Catalog Display
- 🔍 Product Search Functionality
- ❤️ Wishlist System
- 🛍️ Shopping Cart Feature
- 📱 Responsive Design
- 🎨 Modern UI/UX
- 💾 Local Storage Integration

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
